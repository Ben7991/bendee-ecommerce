# Appendix — Glossary

| Term                  | Meaning                                                                                                              |
| --------------------- | -------------------------------------------------------------------------------------------------------------------- |
| **Abandoned cart**    | A cart with ≥ 1 item, no resulting order and no activity for the abandonment window (default 60 min).                |
| **AOV**               | Average Order Value — average order total at placement ([05 §3](../05-analytics-reporting.md#3-metric-definitions)). |
| **AT Money**          | AirtelTigo's mobile money service.                                                                                   |
| **Available stock**   | `onHand − reserved` for a variant at a location.                                                                     |
| **Canonical URL**     | The preferred URL of a page, declared to search engines with `rel="canonical"`.                                      |
| **CAPI**              | Meta Conversions API — server-to-server conversion events.                                                           |
| **CLV**               | Customer Lifetime Value — total (historical) or expected (predictive) value of a customer.                           |
| **COD**               | Cash (or MoMo) on delivery — customer pays the rider on delivery.                                                    |
| **COGS**              | Cost of goods sold — unit cost × units sold.                                                                         |
| **Compare-at price**  | Original price shown struck through next to a sale price.                                                            |
| **DOI**               | Days of inventory — how many days current stock lasts at current sales velocity.                                     |
| **E.164**             | International phone number format, e.g. `+233241234567`.                                                             |
| **GETFund levy**      | Ghana Education Trust Fund levy, charged with VAT on taxable supplies.                                               |
| **GhanaPost GPS**     | Ghana's national digital address system, codes like `GA-123-4567`.                                                   |
| **GRA**               | Ghana Revenue Authority.                                                                                             |
| **Idempotency key**   | Client-supplied key making a repeated request have the same effect as one request.                                   |
| **ISR**               | Incremental Static Regeneration — Next.js caching of server-rendered pages revalidated on change.                    |
| **JSON-LD**           | JSON format for schema.org structured data embedded in pages.                                                        |
| **LCP**               | Largest Contentful Paint — Core Web Vital for perceived load speed.                                                  |
| **MoMo**              | Mobile money — MTN MoMo, Telecel Cash, AT Money.                                                                     |
| **NHIL**              | National Health Insurance Levy, charged with VAT.                                                                    |
| **Outbox**            | Table where domain events are written in the same DB transaction as the change, then relayed to the queue.           |
| **Pesewa**            | 1/100 of a Ghana cedi; the unit used to store money.                                                                 |
| **PDP / PLP**         | Product detail page / product listing page.                                                                          |
| **Pixel**             | Browser-side tracking script from an ad platform (Meta, Google, TikTok).                                             |
| **RBAC**              | Role-based access control.                                                                                           |
| **Recovery flow**     | Automated sequence of messages to bring back a shopper who abandoned a cart or payment.                              |
| **Reservation**       | Temporary hold on stock between payment initiation and success/expiry.                                               |
| **RFM**               | Recency, Frequency, Monetary — customer segmentation method.                                                         |
| **RMA**               | Return merchandise authorisation — a return request and its workflow.                                                |
| **Sell-through rate** | Units sold / (units sold + units remaining) for a period.                                                            |
| **SKU**               | Stock keeping unit — unique code per variant.                                                                        |
| **Slug**              | URL-safe identifier derived from a name, e.g. `kente-print-midi-dress`.                                              |
| **Snapshot**          | Copy of data (price, name, address) stored on an order at placement so later edits don't change it.                  |
| **Telecel Cash**      | Telecel Ghana's (formerly Vodafone Cash) mobile money service.                                                       |
| **TOTP**              | Time-based one-time password (authenticator app) used for staff 2FA.                                                 |
| **Turnover**          | Inventory turnover — COGS / average inventory value at cost.                                                         |
| **UTM**               | `utm_source`, `utm_medium`, `utm_campaign`… URL parameters for campaign attribution.                                 |
| **Variant**           | A purchasable combination of product options (e.g. Red / Size 42).                                                   |
| **Zone**              | Delivery zone — a group of regions/cities/areas sharing delivery methods, fees and ETAs.                             |
